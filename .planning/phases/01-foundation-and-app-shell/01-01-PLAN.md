Edit ShareXMac.Core/ShareXMac.Core.csproj to add these properties inside the first `<PropertyGroup>`:
```xml
<Nullable>enable</Nullable>
```

The `<EnableWindowsTargeting>false</EnableWindowsTargeting>` line is critical — it causes the compiler to emit an error if any code in Core references `System.Drawing` or other Windows-only APIs, catching GDI+ usage at build time rather than runtime.

  <action>
Create ShareXMac.App/entitlements.plist with the exact content below. The `cs.allow-jit` entitlement is mandatory — without it, notarized .NET apps crash immediately because the hardened runtime blocks JIT. The `cs.disable-library-validation` is required for Avalonia to load its native backend dylibs:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <!-- Required for non-NativeAOT .NET: hardened runtime blocks JIT without this -->
    <key>com.apple.security.cs.allow-jit</key>
    <true/>
    <!-- Required for Avalonia: loads native platform dylibs at runtime -->
    <key>com.apple.security.cs.disable-library-validation</key>
    <true/>
</dict>
</plist>
```

Create ShareXMac.App/Info.plist. The NSScreenCaptureUsageDescription key is required by macOS — without it the OS silently refuses screen capture access. NSAppleEventsUsageDescription is needed for window enumeration. CFBundleIdentifier must be a stable reverse-DNS string — this is the identity macOS TCC uses to remember granted permissions across app launches:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>CFBundleName</key>
    <string>ShareXMac</string>
    <key>CFBundleIdentifier</key>
    <string>com.sharexmac.app</string>
    <key>CFBundleVersion</key>
    <string>1.0.0</string>
    <key>CFBundleShortVersionString</key>
    <string>1.0</string>
    <key>CFBundlePackageType</key>
    <string>APPL</string>
    <key>LSUIElement</key>
    <true/>
    <key>NSHighResolutionCapable</key>
    <true/>
    <key>NSScreenCaptureUsageDescription</key>
    <string>ShareXMac needs screen recording access to capture screenshots and recordings.</string>
    <key>NSAppleEventsUsageDescription</key>
    <string>ShareXMac requires AppleScript access to identify application windows.</string>
    <key>LSMinimumSystemVersion</key>
    <string>12.3</string>
</dict>
</plist>
```

Note: `LSUIElement = true` hides the Dock icon — this is correct for a menu bar app that should not appear in the Dock or App Switcher.

Edit ShareXMac.App/ShareXMac.App.csproj to reference both files in the `<PropertyGroup>`:

```xml
<CodesignEntitlements>entitlements.plist</CodesignEntitlements>
```

```xml
</ItemGroup>
```
