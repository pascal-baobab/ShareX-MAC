  <action>
Rewrite ScreenCaptureKitBridge.cs to implement the full ICaptureService interface. Keep the existing P/Invoke declarations and BGRA32-to-PNG conversion pattern. Add:

**New P/Invoke declarations needed:**
1. `CGGetActiveDisplayList(uint maxDisplays, uint[] displays, out uint displayCount)` — from CoreGraphics. Returns active display IDs.
2. `CGDisplayBounds(uint displayId)` — returns CGRect for a specific display (needed for multi-monitor offset calculations).

**Method implementations:**

1. `CaptureFullScreenAsync(uint displayId)`: Call `CGWindowListCreateImage` with a CGRect matching the display bounds from `CGDisplayBounds(displayId)`. Use `kCGWindowListOptionOnScreenOnly` (0x01) and `kCGNullWindowID` (0). Convert BGRA32 pixel data to PNG via ImageSharp `Image.LoadPixelData<Bgra32>`. Return `new CaptureResult(pngBytes, CaptureMode.FullScreen, DateTimeOffset.UtcNow, width, height, displayId)`.

2. `CaptureAllScreensAsync()`: Call `CGWindowListCreateImage` with `CGRect.Null` (all zeros = entire virtual screen across all monitors). Same pixel conversion. Return `CaptureMode.AllScreens`.

3. `CaptureRegionAsync(CGRectCapture rect, uint displayId)`: The `rect` parameter uses Avalonia convention (origin top-left). Convert to Cocoa coordinates: `cocoaY = displayHeight - rect.Y - rect.Height`. Call `CGWindowListCreateImage` with the converted CGRect. Return `CaptureMode.Region`.

4. `CaptureFreezeAsync(uint displayId)`: Identical to `CaptureFullScreenAsync` but returns `CaptureMode.Freeze`. The caller (region selector) displays this as a fullscreen overlay bitmap.

5. `GetActiveDisplayIds()`: Call `CGGetActiveDisplayList(16, displays, out count)`. Return `displays[..count]`. Max 16 displays is reasonable.

**Helper method — keep the existing pattern:**
Extract a private `CaptureImageToResult(CGRect bounds, uint listOption, uint windowId, uint imageOption, CaptureMode mode, uint displayId)` method that encapsulates: CGWindowListCreateImage -> CGImageGetWidth/Height -> CGDataProviderCopyData -> BGRA32 -> ImageSharp PNG. All public methods call this helper.

**Constants to define:**
```csharp
private const uint kCGWindowListOptionOnScreenOnly = 0x01;
private const uint kCGNullWindowID = 0;
private const uint kCGWindowImageDefault = 0;
private const uint kCGWindowImageBoundsIgnoreFraming = 0x01;
private const uint kCGWindowListOptionIncludingWindow = 0x08;
```

**Important:** Keep `AllowUnsafeBlocks` in csproj (already set). Continue using `unsafe { fixed (byte* ptr = ...) }` for pixel data if needed. Do NOT use System.Drawing. Do NOT add net9.0-macos TFM — stay on net9.0 with pure P/Invoke.

Add CaptureWindowAsync and GetWindowListAsync to the ScreenCaptureKitBridge written in Task 1.

**New P/Invoke declarations:**
1. `CGWindowListCopyWindowInfo(uint option, uint relativeToWindow)` — returns CFArrayRef of CFDictionary
2. `CFArrayGetCount(IntPtr array)` — count of items in CFArray
3. `CFArrayGetValueAtIndex(IntPtr array, nint index)` — get item from CFArray
4. `CFDictionaryGetValue(IntPtr dict, IntPtr key)` — get value by key from CFDictionary
5. `CFNumberGetValue(IntPtr number, int type, out int value)` — extract int from CFNumber
6. `CFNumberGetValue(IntPtr number, int type, out double value)` — extract double from CFNumber (overload)
7. `CFStringCreateWithCString(IntPtr allocator, string str, uint encoding)` — create CFString for dictionary key lookup

**Constants needed for CGWindowListCopyWindowInfo:**
```csharp
private const uint kCGWindowListOptionOnScreenOnly = 0x01;
private const uint kCGWindowListExcludeDesktopElements = 0x10;
// CFNumber types
private const int kCFNumberSInt32Type = 3;
private const int kCFNumberFloat64Type = 13;
// kCFStringEncodingUTF8
private const uint kCFStringEncodingUTF8 = 0x08000100;
```

**CGWindowListCopyWindowInfo dictionary keys** (as CFString constants):
- `"kCGWindowNumber"` -> WindowId (uint)
- `"kCGWindowOwnerName"` -> OwnerName (string)
- `"kCGWindowName"` -> WindowName (string, nullable)
- `"kCGWindowBounds"` -> sub-dictionary with X, Y, Width, Height
- `"kCGWindowLayer"` -> Layer (int)

**GetWindowListAsync implementation:**
1. Call `CGWindowListCopyWindowInfo(kCGWindowListOptionOnScreenOnly | kCGWindowListExcludeDesktopElements, kCGNullWindowID)`
2. Iterate CFArray, for each CFDictionary extract: WindowId, OwnerName, WindowName, bounds (X, Y, Width, Height), Layer
3. Filter to `Layer == 0` (normal windows; menu bar and dock have different layers)
4. Convert CFDictionary bounds to WindowInfo record
5. Return `List<WindowInfo>` ordered front-to-back (the order CGWindowListCopyWindowInfo returns)
6. Always `CFRelease` the CFArray after extraction

**CaptureWindowAsync implementation:**
1. Use `kCGWindowListOptionIncludingWindow` (0x08) with the specific `windowId`
2. Shadow toggle: `includeShadow ? kCGWindowImageDefault (0) : kCGWindowImageBoundsIgnoreFraming (0x01)`
3. Pass `CGRect.Null` for bounds (let CGWindowList compute the window's own bounds)
4. Use the same pixel-data-to-PNG helper from Task 1
5. Return `new CaptureResult(pngBytes, CaptureMode.Window, DateTimeOffset.UtcNow, width, height)`

**CFString helper for dictionary key lookup:**
Create a helper `CreateCFString(string s)` that calls `CFStringCreateWithCString(IntPtr.Zero, s, kCFStringEncodingUTF8)`. Cache the key CFStrings (kCGWindowNumber, kCGWindowOwnerName, etc.) as static readonly fields to avoid re-creation.

**CFDictionary value extraction helpers:**
- `GetIntValue(IntPtr dict, IntPtr key)` -> int? (uses CFNumberGetValue with kCFNumberSInt32Type)
- `GetDoubleValue(IntPtr dict, IntPtr key)` -> double? (uses CFNumberGetValue with kCFNumberFloat64Type)
- `GetStringValue(IntPtr dict, IntPtr key)` -> string? (uses CFStringGetCStringPtr or CFStringGetCString fallback)

Add P/Invoke for `CFStringGetCStringPtr(IntPtr str, uint encoding)` and `CFStringGetLength(IntPtr str)` to extract string values from CFDictionary.

**Important:** All CFRelease calls must be in try/finally blocks. Do NOT use System.Drawing. Keep all P/Invoke in `/System/Library/Frameworks/CoreGraphics.framework/CoreGraphics` and `/System/Library/Frameworks/CoreFoundation.framework/CoreFoundation`.
