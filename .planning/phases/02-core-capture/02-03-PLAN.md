**ShareXMac.App/Views/RegionSelectorWindow.axaml.cs:**
The code-behind is the SkiaSharp rendering engine. It must:

1. Override `OnOpened` to set `Cursor = new Cursor(StandardCursorType.Cross)`.
2. Override `Render(DrawingContext context)` to draw the overlay using an `ICustomDrawOperation` that receives an SKCanvas.
3. Handle `PointerPressed`, `PointerMoved`, `PointerReleased` events in OnAttachedToVisualTree or constructor.
4. Handle `KeyDown` for Escape (cancel), Enter (confirm), Space (freeze toggle), Shift (constrain to square), Ctrl/Cmd (anchor from center).

**SkiaSharp rendering inside ICustomDrawOperation.Render(ISkiaSharpApiLease lease):**

a) **Screen dim:** Fill entire canvas with `new SKPaint { Color = new SKColor(0, 0, 0, 128) }` (50% black, #80000000).

b) **Clear selected region** (if dragging): Use `canvas.Save()`, set clip to selection rect, call `canvas.Clear(SKColors.Transparent)` to punch a hole in the dim. Then draw the 10% accent fill `new SKColor(0x3E, 0x83, 0xF2, 0x1A)` inside the selection rect. Restore canvas.

c) **Selection rectangle border:** `SKPaint { Color = new SKColor(0x3E, 0x83, 0xF2), StrokeWidth = 2, Style = SKPaintStyle.Stroke }` — accent blue #3E83F2, 2px solid.

d) **Crosshair lines:** Two lines through cursor position, full width and full height. White (#FFFFFF) with a 1px black (#000000) shadow at offset (1,1). Draw black first, then white on top.

e) **Dimension label:** Dark pill below-right of selection (8px offset). Background: `#CC000000` (80% black). Text: white #FFFFFF, 12px SemiBold. Content: "W x H" during drag (e.g., "1920 x 1080"), "X: {x}, Y: {y}" before drag. Pill has 6px horizontal padding, 2px vertical padding, 4px corner radius. If off-screen bottom-right, flip to above top-left.

f) **Magnifier loupe:** 100px diameter circle, positioned 16px above-right of cursor. Clip to circle, draw 5x zoomed portion of screen centered on cursor. After zoom content: draw 2px white border circle, then 1px red (#FF0000) crosshair with 20px arms centered in the circle. Draw 1px #40FFFFFF grid lines between pixels at 5x zoom. If near top-right screen edge, flip to below-left.

For the magnifier to work, the code-behind needs a bitmap of the current screen. On overlay open, capture a screenshot bitmap via ICaptureService.CaptureFullScreenAsync (or CaptureFreezeAsync if frozen) and load it as an SKBitmap. The magnifier samples from this bitmap.

**Freeze mode:** When Space is pressed, call `CaptureFreezeAsync` to get the frozen screen bitmap. Replace the live screen bitmap with the frozen one. Show "Screen Frozen" indicator text at top-center of overlay (white text on dark pill, same style as dimension label).

**Mouse tracking flow:**
- PointerMoved: Update cursor position in ViewModel. If dragging, update selection rect. Trigger InvalidateVisual() to repaint.
- PointerPressed: Start drag. Record startX, startY.
- PointerReleased: End drag. Call ViewModel.ConfirmSelection() which invokes CaptureRegionAsync.

**Keyboard flow:**
- Escape: ViewModel.Cancel() -> Close window, no capture.
- Enter: ViewModel.ConfirmSelection() if selection exists.
- Space: ViewModel.ToggleFreeze().
- Shift held during drag: Constrain selection to square (min of width/height applied to both).
- Ctrl/Cmd held during drag: Anchor from center of start point instead of corner.

```csharp
public sealed class WindowPickerViewModel : ReactiveObject
{
    private readonly ICaptureService _captureService;

    [Reactive] public double CursorX { get; set; }
    [Reactive] public double CursorY { get; set; }
    [Reactive] public WindowInfo? HoveredWindow { get; set; }
    [Reactive] public bool IncludeShadow { get; set; } = true;

    public IReadOnlyList<WindowInfo> Windows { get; private set; } = Array.Empty<WindowInfo>();

    public CaptureResult? Result { get; private set; }
    public event Action? CaptureCompleted;
    public event Action? Cancelled;

    public WindowPickerViewModel(ICaptureService captureService) { _captureService = captureService; }

    public async Task LoadWindowsAsync()
    {
        Windows = await _captureService.GetWindowListAsync();
    }

    public void UpdateCursorPosition(double x, double y)
    {
        CursorX = x;
        CursorY = y;
        // Hit-test: find the frontmost window whose bounds contain (x, y)
        HoveredWindow = Windows.FirstOrDefault(w =>
            x >= w.X && x <= w.X + w.Width &&
            y >= w.Y && y <= w.Y + w.Height);
    }

    public async Task SelectWindow()
    {
        if (HoveredWindow == null) return;
        Result = await _captureService.CaptureWindowAsync(HoveredWindow.WindowId, IncludeShadow);
        CaptureCompleted?.Invoke();
    }

    public void ToggleShadow() { IncludeShadow = !IncludeShadow; }
    public void Cancel() { Result = null; Cancelled?.Invoke(); }
}
```

On overlay `OnOpened`, call `await ViewModel.LoadWindowsAsync()` to populate the window list. The list is fetched once on open, not continuously polled.

**Important:** The window highlight overlay rect uses the window's Cocoa coordinates from CGWindowListCopyWindowInfo. These must be converted to Avalonia screen coordinates for drawing. Cocoa origin is bottom-left, Avalonia is top-left. Convert: `avaloniaY = screenHeight - cocoaY - windowHeight`.
