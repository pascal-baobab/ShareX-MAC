# Phase 02 — UI Design Contract: Core Capture

> Visual and interaction contract for the capture overlay, preview thumbnail, and history UI. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | Avalonia FluentTheme + ShareX custom theme layer |
| Preset | not applicable (native desktop, not web) |
| Component library | Avalonia built-in controls (FluentTheme), custom SkiaSharp overlays |
| Icon library | Lucide (lucide.ttf bundled in ShareX.ImageEditor/Assets/) |
| Font | System default: San Francisco on macOS (resolved via FluentTheme), Inter fallback for cross-platform |

> Note: The project uses Avalonia UI with AXAML styling, not web technologies. All design tokens are expressed as Avalonia resource dictionary values, not CSS/Tailwind. The existing ImageEditorTheme.axaml defines a complete light/dark color system that this phase extends.

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, inline padding within overlay HUD elements |
| sm | 8px | Spacing between overlay controls, StackPanel default Spacing |
| md | 16px | Default panel Margin, card internal padding |
| lg | 24px | Section padding within MainWindow History tab |
| xl | 32px | PermissionWizard-style outer margins, page-level insets |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Region selector dimension label padding: 6px horizontal, 2px vertical (tight fit for floating HUD)
- Preview thumbnail window total size: 280x80px (fixed size, not governed by spacing scale)
- Crosshair line thickness: 1px (pixel-precise, not spacing-scale)

---

## Typography

All sizes reference device-independent pixels as used by Avalonia. The existing project baseline font size is 13px (from `ShareX.FontSize.Default`).

| Role | Size | Weight | Line Height | Avalonia Resource |
|------|------|--------|-------------|-------------------|
| Body | 13px | SemiBold (600) | 1.4 | `ShareX.FontSize.Default` (existing) |
| Label / HUD | 11px | Regular (400) | 1.2 | New: `ShareX.FontSize.Small` |
| Heading | 16px | Bold (700) | 1.3 | Inline in views (existing pattern from MainWindow) |
| Dimension overlay | 12px | SemiBold (600) | 1.0 | Rendered by SkiaSharp SKPaint, not AXAML |

Usage mapping:
- **Body (13px SemiBold):** History list item text (filename, date), preview thumbnail action labels, filter dropdowns
- **Label/HUD (11px Regular):** Region selector dimension text ("1920 x 1080"), crosshair coordinate readout, preview auto-dismiss countdown, history metadata (file size, capture mode badge)
- **Heading (16px Bold):** "History" tab header in MainWindow sidebar, empty state title
- **Dimension overlay (12px SemiBold):** SkiaSharp-rendered text on the capture overlay canvas; drawn with SKPaint not AXAML TextBlock

| Element | Value | Purpose |
|---------|-------|---------|

| Selection border | `#3E83F2` (accent blue) | 2px solid border around the dragged selection rectangle |

Accent reserved for:
- Selected history item highlight border
- Active capture mode indicator in tray menu

- "Copy" and "Save" action button backgrounds on preview thumbnail

## Interaction Contracts

### Region Selector

| Interaction | Behavior |
|-------------|----------|
| Launch | Screen dims to 50% black immediately. Cursor changes to crosshair. |
| Mouse move (before drag) | Crosshair follows cursor. Dimension label shows cursor coordinates "X: 1234, Y: 567" in a dark pill anchored 8px below and 8px right of cursor. Magnifier loupe (5x zoom, 100x100px circle) appears 16px above-right of cursor. |
| Mouse down + drag | Selection rectangle appears with accent blue 2px border and 10% accent blue fill. Dimension label switches to "W x H" format showing selection size. Area outside selection remains dimmed. |
| Mouse up | Selection completes. Region is captured via ICaptureService.CaptureRegionAsync. Overlay dismisses. CapturePreviewPopup appears. |
| Escape key | Cancel capture. Dismiss overlay. No capture taken. |
| Enter key | Confirm current selection (if selection exists). Same as mouse up. |
| Space key | Toggle freeze mode: captures current screen as frozen bitmap, continues region selection over the frozen image. |
| Multi-monitor | One RegionSelectorWindow per display (from GetActiveDisplayIds). Selection can start on one display only. Unified coordinate system via CGGetActiveDisplayList. |

### Window Picker

| Interaction | Behavior |
|-------------|----------|
| Launch | Screen dims to 50% black. Cursor is default pointer. |
| Mouse move over window | Hovered window gets 30% accent blue overlay highlight. Window title and app name appear in a floating label near the top of the highlighted window. |
| Click | Selected window is captured via ICaptureService.CaptureWindowAsync. Overlay dismisses. CapturePreviewPopup appears. |
| Escape key | Cancel. Dismiss overlay. |
| Tab key | Toggle window shadow inclusion (with/without). Visual indicator in corner shows current shadow state. |

### Capture Preview Popup

| Interaction | Behavior |
|-------------|----------|
| Appear | Slides in from bottom-right with 200ms ease-out animation. |
| Layout | Left: 60x60px thumbnail of captured image. Right: 3 icon buttons stacked vertically (Copy, Save, Open). |
| Auto-dismiss | 5-second countdown. Thin progress bar at bottom of popup depletes left-to-right over 5 seconds. |
| Hover | Pauses auto-dismiss countdown. Progress bar freezes. |
| Mouse leave | Resumes countdown from where it paused. |
| Click "Copy" | Copies to clipboard (already done by default, but re-triggers if user changed clipboard). Brief checkmark flash on button. |
| Click "Save" | Opens Finder to the saved file location. |
| Click "Open" | Opens annotation editor (Phase 4 stub: shows file in Preview.app). |
| Click thumbnail | Expands to full capture detail view in MainWindow History tab. Dismisses popup. |
| Manual dismiss | Click X button in top-right corner of popup. Immediate dismiss with 150ms fade-out. |

### History View

| Interaction | Behavior |
|-------------|----------|
| Default view | Grid of HistoryItemCards, 3 columns, sorted newest-first. Each card: 100x100 thumbnail, filename below, date + mode badge below that. |
| Search | TextBox at top. Filters by filename (contains match). Debounced 300ms. |
| Filter chips | Row of toggle chips below search: "All", "Region", "Window", "Full Screen", "Freeze". Click to filter by CaptureMode. Active chip uses accent background. |
| Card hover | Subtle elevation increase (BoxShadow deepens). |
| Card click | Selects card. Shows detail panel on right side: full-size preview, file path, dimensions, date/time, Copy/Re-save/Delete actions. |
| Card right-click | Context menu: "Copy to Clipboard", "Show in Finder", "Delete". |
| Delete | Confirmation dialog: "Delete this capture from history? The file on disk will not be removed." Two buttons: "Cancel" (default focus) and "Delete" (destructive red). |
| Empty state | Centered in history panel. Icon + heading + body text (see Copywriting Contract below). |
| Scroll | Virtualized list (Avalonia ItemsRepeater or ListBox with VirtualizationMode). Loads thumbnails from SQLite ThumbnailBytes column. |

## Overlay Rendering Contract (SkiaSharp)

The region selector and window picker use custom SkiaSharp rendering via `ICustomDrawOperation`, not standard Avalonia controls. This section specifies the exact rendering parameters.

### Crosshair

| Property | Value |
|----------|-------|
| Line width | 1px (device pixel) |
| Line color | White (#FFFFFF) with 1px black (#000000) drop shadow offset (1,1) |
| Extends | Full screen width horizontally, full screen height vertically, passing through cursor position |
| Gap at cursor | 0px (lines meet at cursor point) |

### Selection Rectangle

| Property | Value |
|----------|-------|
| Border width | 2px |
| Border color | `#3E83F2` (accent) |
| Border style | Solid, no dash |
| Fill color | `#1A3E83F2` (10% accent) |
| Corner radius | 0px (pixel-precise rectangle) |

### Dimension Label

| Property | Value |
|----------|-------|
| Background | `#CC000000` (80% black) |
| Text color | `#FFFFFF` |
| Font | System default (SKTypeface.Default), 12px |
| Font weight | SemiBold |
| Padding | 6px horizontal, 2px vertical |
| Corner radius | 4px |
| Position | 8px below selection bottom-right corner; if off-screen, flips to above selection top-left |

### Magnifier Loupe

| Property | Value |
|----------|-------|
| Size | 100px diameter circle |
| Zoom | 5x magnification |
| Border | 2px white (#FFFFFF) |
| Internal crosshair | 1px red (#FF0000), 20px arms, centered |
| Position | 16px above-right of cursor; flips to below-left if near screen edge |
| Pixel grid | At 5x zoom, individual pixels are visible; draw 1px #40FFFFFF grid lines between pixels |

## Accessibility Contract

| Element | Requirement |
|---------|-------------|
